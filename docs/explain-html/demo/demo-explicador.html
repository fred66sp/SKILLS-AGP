Cómo funciona explain-html

Un encargo entra, un único .html sale y se abre en el navegador. El recorrido tiene cinco decisiones y una puerta que no se puede saltar.

contrato 0.3.0 6 pasos · 1 puerta código real resaltado
1

TL;DR

Qué es

Una skill que convierte un encargo de revisión en un artefacto HTML autocontenido dentro de .explanations/.

Por qué importa

Cambia un muro de Markdown por un documento que se abre, se navega y se interactúa. Lo verificado lleva fuente; lo que no se pudo verificar va a «Desconocidos».

Dónde está

src/explain-html/SKILL.md:112-155 fija el procedimiento; scripts/check-artifact.py:185-246 es la puerta que decide si el artefacto se entrega.

2

El flujo completo

La caja acentuada es donde se decide la familia; la verde es la puerta. Si la puerta falla, no se abre: se corrige y se vuelve a ejecutar.

3

Recorrido por pasos

Cada paso con lo que produce y con el fragmento real que lo gobierna. El detalle vive en el contrato; aquí se lee el mecanismo.

1. Fijar el encargo

Propósito, audiencia y momento de uso: qué debe poder hacer la persona con el artefacto —leer, comparar, decidir, interactuar, copiar—. Si falta una decisión que cambia la familia o el alcance, se pregunta antes de generar.

SKILL.md:114-117. Para detalles reversibles, la suposición se declara dentro del propio artefacto.

2. Reunir y verificar el material

Código, documentación, historial git, salidas de comandos y los ficheros que la persona señale. Cada dato verificado lleva su fuente; el resto no se rellena: se enumera como desconocido con la pregunta que lo desbloquearía.

SKILL.md:119-122.

3. Elegir familia y copiar la plantilla

Ocho familias, una plantilla cada una. Se copia la de la familia elegida, no se rodea con otra inventada; el esqueleto base queda solo para encargos que no encajan en ninguna.

cp assets/plantilla-informe.html ../../.explanations/estado-semana-45.html

SKILL.md:124-128.

4. Generar: procedencia, tokens y código

Se rellena el bloque de procedencia con el prompt real, la fecha, el slug de la familia y las fuentes. Si el proyecto declara sistema visual, se copian sus valores en el :root; si el artefacto muestra código, se resalta con el script propio.

python3 scripts/tokens-from-project.py ../../DESIGN.md
python3 scripts/highlight.py python ../../src/x.py

La precedencia es intención de la persona → sistema del proyecto → defaults de la plantilla. Nunca se enlaza el CSS del proyecto.

5. Verificar, revisar a ojo y abrir

La puerta comprueba autocontención, HTML bien formado, título, procedencia y enlaces; avisa del contraste de los tokens y del tamaño. Después, la revisión perceptiva mira el render a 390, 768 y 1440 px. Un artefacto que no pasa no se entrega ni se abre.

def check_artifact(path: Path) -> tuple[list[str], list[str]]:
    """Devuelve (errores, avisos): los errores impiden la entrega, los avisos no."""
    errors: list[str] = []
    warnings: list[str] = []
    try:
        text = path.read_text(encoding="utf-8")
    except FileNotFoundError:
        return [f"{path}: el fichero no existe. Genera el artefacto antes de verificarlo."], warnings
    except UnicodeDecodeError as exc:
        return [f"{path}: no es texto UTF-8 ({exc}); un HTML de texto plano no debería fallar aquí."], warnings

    if path.suffix.lower() != ".html":
        errors.append(f"{path}: la extensión no es .html; los artefactos son un único .html.")

    title = TITLE.search(text)
    if not title:
        errors.append(f"{path}: falta <title>. Un artefacto sin título no se encuentra ni se nombra en el cierre.")
    elif "ASUNTO DEL ARTEFACTO" in title.group("val"):
        errors.append(f"{path}: <title> conserva el marcador de la plantilla; pon el asunto concreto.")

    meta = artifact_meta.find(text)
    if meta is None:
        errors.append(f"{path}: {artifact_meta.MISSING}")
    else:
        _, problems = artifact_meta.load(meta)
        for problem in problems:
            errors.append(f"{path}:{line_of(text, meta.start())}: {problem}")

check-artifact.py:185-246. Los errores impiden la entrega; los avisos se corrigen o se justifican en el cierre.

4

Trampas

Lo que se cree que funciona y no pasa la puerta.

Copiar tokens no es enlazar CSSUn <link>, un @import o un url() externo rompen la autocontención. Los valores se copian como custom properties; el fichero debe abrirse igual por file://.

Un artefacto no se sobrescribeUna vuelta nueva es un fichero nuevo: <slug>-v2.html. lifecycle.py conserva por defecto las tres últimas versiones y nunca borra la vigente.

El índice no es un catálogo publicado.explanations/index.html es local y regenerable. Este catálogo de demos es otra cosa: documentación versionada en docs/.

El pie no es la procedenciaEl comentario del inicio del body es lo que lee el verificador y el índice. Un pie visible puede editarse; el comentario, no se sustituye.

5

Desconocidos

  • El script no mide la calidad ni la accesibilidad completa: la revisión perceptiva es un criterio humano o automatizado, no una garantía.
  • No hay una medición de lectura que demuestre que este medio se lee más que el Markdown; la afirmación del contrato es una hipótesis de trabajo.
  • La cifra de 100 KB es un umbral operativo, no una recomendación de rendimiento medida.
