Propose 1

Proposal: exportación por lotes

proposalproposeopenspec

Exportar de una en una obliga a repetir el mismo gesto por cada nota. Quien prepara una entrega necesita sacar una selección completa de una vez.

Specify 2

Delta: export-notes

deltasspecifyopenspec
Export a batch of notesADDED

El sistema SHALL exportar las notas seleccionadas en un único fichero con un índice al principio, con una respuesta rápida.

Escenario: Lote de tres notas

GIVEN
  • tres notas seleccionadas en la lista
WHEN
  • la persona pide exportarlas juntas
THEN
  • el sistema escribe un fichero con el índice y las tres notas.

Escenario: Lote vacío

GIVEN
  • una selección vacía
WHEN
  • la persona pide exportarla
THEN
  • el sistema avisa y no escribe ningún fichero.
Export a single noteMODIFIED

El sistema SHALL exportar una nota concreta a un fichero Markdown y SHALL aceptar `--format=json` cuando la persona lo pida.

Escenario: Exportación con formato elegido

GIVEN
  • una nota existente
WHEN
  • la persona elige el formato JSON
THEN
  • el sistema escribe el fichero con ese formato.

Export notes · spec vigente

specsspecifyopenspec
Export a single note

El sistema SHALL exportar una nota concreta a un fichero Markdown con su título y su cuerpo.

Escenario: Exportación correcta

GIVEN
  • una nota existente
WHEN
  • la persona pide exportarla
THEN
  • el sistema escribe el fichero y confirma la ruta.

Escenario: Nota inexistente

GIVEN
  • un identificador que no existe
WHEN
  • la persona pide exportarla
THEN
  • el sistema responde con un error y no escribe nada.

Design 1

Design: exportación por lotes

designdesignopenspec

La selección vive en el estado de la lista, no en el documento: se guarda un conjunto de identificadores y se vacía al cambiar de cuaderno. La exportación recorre la selección en el orden en que aparece en la lista y escribe un solo fichero para que la entrega tenga un único destino.
