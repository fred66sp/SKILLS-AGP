# Enrutador de la skill de límites de arquitectura frontend

Esta carpeta existe solo para que la skill se descubra. El contrato y sus detalles viven en un único sitio y no se copian aquí.

1. Lee `../../src/frontend-architecture-boundaries/SKILL.md` completo, hasta el final, antes de auditar, decidir o implementar ningún límite.
