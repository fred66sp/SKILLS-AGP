# Enrutador de la skill de estilo JavaScript

Esta carpeta existe solo para que la skill se descubra. El contrato y sus detalles viven en un único sitio y no se copian aquí.

1. Lee `../../src/javascript-idiomatic-style/SKILL.md` completo, hasta el final, antes de escribir o revisar JavaScript.
2. Abre sus `references/` solo cuando el paso en curso lo pida. No reformatees código ajeno para imponer la skill ni dupliques reglas en otro sitio.
3. No apliques ninguna regla que no aparezca en ese `SKILL.md` o en sus referencias. Si este enrutador y el paquete difieren, manda el paquete.
