Contraste de los pares

Medido con la fórmula WCAG sobre los valores exportados. Un par por debajo de 4.5:1 no se usa como texto.

ParClaroOscuroMínimo
Texto sobre papel— AA— AA4.5:1
Texto atenuado sobre papel— AA— AA4.5:1
Acento como texto— AA— AA4.5:1
Texto sobre acento— AA— AA4.5:1

Un acento de familia no siempre vale como texto. Si un color no llega a AA sobre el fondo, sirve para halos y bordes, no para texto normal.

3

Exportar

El bloque copia solo los valores que cambian; el resto del sistema se conserva. La exportación es texto listo para pegar, no un fichero.
